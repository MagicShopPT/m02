Tipografia, Cores e Variáveis CSS

Guia prático de referência para estruturar a leitura, a hierarquia visual e a consistência cromática em interfaces web.

  • 1. Tipografia Base
  • 2. Títulos e Legibilidade
  • 3. Variáveis CSS (Custom Properties)
  • 4. Ligações e Estados

1. Tipografia Base

A definição de uma boa base tipográfica começa no elemento body. Combinar uma família de tipos legível (font-family), um tamanho de base confortável (font-size) e um espaçamento vertical adequado entre linhas (line-height) reduz a fadiga visual em textos técnicos longos.

Para trechos de código ou nomes de propriedades, o uso de uma família monoespaçada distingue claramente a sintaxe técnica do texto corrido.

2. Títulos e Legibilidade

Escala e Peso Tipográfico

Os títulos (h1, h2, h3) estabelecem a estrutura hierárquica do documento. Em regra, os títulos utilizam maior font-weight e um line-height mais compacto do que os parágrafos, facilitando a leitura rápida por secções. 

body {
    font-family: var(--font-sans);
    font-size: var(--text-base);
    line-height: var(--leading-body);
    color: var(--color-text);
    background: var(--color-bg);
}

3. Variáveis CSS (Custom Properties)

As variáveis CSS (declaradas com prefixo --, habitualmente em :root) permitem centralizar cores, fontes, tamanhos e espaçamentos[cite: 13]. Ao consumir estes valores através da função var(), qualquer atualização num único ponto reflete-se em toda a folha de estilos[cite: 13].

  • Cores: --color-bg, --color-surface, --color-text, --color-primary, --color-accent.
  • Tipografia: --font-sans, --font-mono, --text-base, --leading-body.

4. Ligações e Estados

As ligações (a) devem ser facilmente identificáveis e manter contraste adequado sobre o fundo. Consultar a documentação MDN sobre CSS ou rever a secção de tipografia base ajuda a validar boas práticas de leitura e acessibilidade.
